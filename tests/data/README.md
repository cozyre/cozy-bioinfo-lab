# Fixture data

All files here are committed once and used by the offline test suite. Tests
must never call live services.

| File | Origin | Notes |
| --- | --- | --- |
| `uniprot_P04637.json` | **Real**, recorded from `rest.uniprot.org/uniprotkb/P04637.json` on 2026-11-17 | Query sequence, organism and 1520 feature annotations. |
| `msa_input.fasta` | **Real** input used for the MSA below | Query + four reviewed/unreviewed UniProt orthologs (H2QC53 chimp, P02340 mouse, P10361 rat, P67939 cow), headers `Species|Accession`. |
| `msa_tp53_five_species.fasta` | **Real**, recorded from the EBI Clustal Omega REST service (job `clustalo-R20261117-114709-0853-79239464-p1m`) | 400-column alignment of the five records above; the §9.4 de-gap hard check must reproduce `msa_input.fasta`. |
| `blast_tp53_five_species.xml` | **SYNTHETIC** — generated by `make_blast_fixture.py` | NCBI's BLAST queue was unreachable (all jobs stuck in WAITING for >2.5 h) on the recording day (2026-11-17). The generator uses the real UniProt query, real RefSeq subject sequences (`NP_*`/`XP_*.fa`, fetched from Entrez the same day) and real Biopython `PairwiseAligner` local alignments with blastp scoring (BLOSUM62, gap open 11 / extend 1); only bit scores (Karlin-Altschul approximation), E-values and the XML document itself are synthesized. Live service calls during recording identified themselves with the project owner's contact email, which is deliberately **not** stored here — users enter their own contact email in the app. Replace with a recorded real XML when NCBI is reachable again — the parser tests then verify the real file. |
| `make_blast_fixture.py` | Generator for the file above | Deterministic; run from the repo root with the project's Python. |
| `NP_*.fa`, `XP_*.fa` | **Real**, recorded from NCBI Entrez efetch on 2026-11-17 | Inputs for the generator, kept for provenance. |

Known scientific facts baked into the BLAST fixture (verified against the real
sequences): human P04637 equals RefSeq `NP_001394193.1` (393/393 identity);
chimpanzee p53 is protein-identical to human p53; mouse `NP_035770.2` and
`XP_006533220.1` tie exactly (bit 715.4, 304/393 identity), which exercises
the NP-over-XP deterministic tie-break in the selection algorithm (§9.2).
